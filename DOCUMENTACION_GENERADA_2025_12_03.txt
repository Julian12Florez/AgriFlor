================================================================================
FLUJOS PRINCIPALES
================================================================================

COMPRA → RECEPCIÓN → INVENTARIO:
  1. Usuario crea Compra (Purchases.tsx)
  2. Sistema guarda Purchase + PurchaseItems
  3. Usuario marca como "received"
  4. Sistema crea Reception automático
  5. Reception actualiza Inventory (agrega stock)
  6. Se generan InventoryMovements

SALIDA → INVENTARIO (FIFO):
  1. Usuario crea Salida (Outputs.tsx)
  2. Sistema valida inventario disponible
  3. Usuario aprueba salida
  4. ProductOutputObserver se dispara automático
  5. Sistema aplica FIFO (primero entra, primero sale)
  6. Inventory se actualiza (resta stock)
  7. Se generan InventoryMovements
  8. Salida se marca como "completed"

PRODUCTO → TODOS:
  1. Usuario gestiona Productos (Products.tsx)
  2. Productos se usan en:
     - PurchaseItem (qué se compra)
     - OutputProduct (qué se saca)
     - Inventory (stock actual)
     - InventoryMovement (historial)

OBSERVACIONES IMPORTANTES
================================================================================

1. UUIDS:
   - Todos los modelos usan UUID (no autoincrement)
   - Mayor seguridad y distribuibilidad

2. TIMESTAMPS:
   - Algunos modelos tienen timestamps: false
   - Se controlan manualmente en controladores

3. OBSERVERS:
   - ProductOutputObserver automatiza procesos
   - Se dispara al crear/actualizar salidas
   - Genera InventoryMovements automático

4. POLIMORFISMO:
   - InventoryMovement es polimórfico
   - Puede relacionarse con Purchase, ProductOutput
   - Facilita auditoria e historial

5. FIFO:
   - Implementado en ProductOutputObserver
   - Primer lote entrante es primer lote saliente
   - Respeta fechas de vencimiento

6. RESPONSIVIDAD:
   - ResponsiveTable adaptable a móvil/desktop
   - Componentes usan Grid system Ant Design
   - Tested en múltiples resoluciones

7. AUTENTICACIÓN:
   - JWT Bearer Token
   - Token en localStorage
   - Auto-logout al expirar token

6. INTEGRACIÓN Y FLUJOS
================================================================================

COMPRA → INVENTARIO:
  1. Usuario crea compra (Purchases.tsx)
  2. Compra se guarda con items
  3. Estado: ordered → in_transit → received
  4. Al recibir, se crea Reception
  5. Reception actualiza Inventory

SALIDA → INVENTARIO:
  1. Usuario crea salida (Outputs.tsx)
  2. Frontend valida inventario disponible
  3. Usuario aprueba salida
  4. ProductOutputObserver ejecuta automáticamente
  5. Inventario se actualiza con FIFO
  6. Se generan InventoryMovements

PRODUCTO → TODOS LOS MÓDULOS:
  • Se usa en Compra como item a comprar
  • Se usa en Salida como item a sacar
  • Se usa en Inventory para control de stock
  • Se relaciona con Brand y Location
